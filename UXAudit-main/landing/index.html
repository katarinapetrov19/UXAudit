Install UXCheck

The extension is currently in early access. Install it in under 2 minutes — no account needed.

1

Download the extension

Grab the latest release from GitHub.

Download ZIP from GitHub
2

Unzip and open Chrome Extensions

Unzip the file, then go to chrome://extensions in your browser. Enable Developer mode (toggle, top right).

3

Load the extension folder

Click Load unpacked and select the extension subfolder inside the unzipped archive — not the root UXAudit-main folder. The correct path ends in UXAudit-main/extension.

4

Run your first audit

Visit any website, click the UXCheck icon in your toolbar, and hit Scan Current Page. Results appear in seconds.
